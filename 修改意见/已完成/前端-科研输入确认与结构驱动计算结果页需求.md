# 前端：科研输入确认与结构驱动计算结果页需求

> 完成状态：已完成\
> 验收日期：2026-07-15\
> 说明：结构驱动工作台、科研状态表达与文献复现详情已按来源隔离；文献基准页面级流程见专项验收记录。

## 1. 目标

用户上传自定义材料结构后，前端不能只显示“计算成功”或直接给出排名。必须引导用户完成科研建模所需的确认，并清楚展示每一步结果的来源、可信度和限制。

本次目标是让用户能够在系统中完成：

```text
上传结构
-> 确认活性位点
-> 选择 Li2S4/Li2S6 吸附构型
-> 确认或导入优化几何
-> 查看并确认电荷、自旋候选与活性空间
-> 查看 Hamiltonian、VQE、分布式执行与能量结果
-> 理解结果是否可用于筛选
```

系统面向的用户不一定懂量子化学，因此不能要求用户凭空填写“总电荷”和“自旋多重度”后就视为正确。前端的职责是解释、收集、约束和记录，而不是伪造科研判断。

## 2. 设计原则

1. “需要确认”不是失败：`needs_model_review` 应展示为“需要补充科研建模信息”，并说明原因与可执行操作。
2. 不显示虚假完成：没有完成 DFT 优化、Hamiltonian、VQE 时，不得提前显示吸附能、量子精修分或材料推荐。
3. 不混淆来源：内置演示材料与用户上传结构必须使用不同标识、不同结果页和不同来源标签。
4. 不让用户猜答案：对电荷、自旋、计算方法提供系统建议、候选比较和术语提示；最终确认由用户或项目化学负责人完成。
5. 全流程可回看：用户能从结果页返回每个模型输入、确认记录、Artifact 和计算日志摘要。

## 3. 新增入口与页面结构

### 3.1 入口

在现有“材料筛选”中增加显著入口：

```text
内置候选材料筛选（演示）
用户自定义结构计算（科研建模）
```

两者不得共用同一个“开始筛选”按钮和同一套结果文案。

### 3.2 页面 1：自定义结构工作台

页面分为步骤导航与当前操作区：

```text
1. 上传与解析
2. 活性位点
3. 吸附构型
4. 优化几何
5. 电荷、自旋与活性空间
6. Hamiltonian 与 VQE
7. 结果与证据链
```

每一步显示：`未开始 / 进行中 / 需要确认 / 已完成 / 失败 / 部分完成`。

## 4. 页面功能要求

### 4.1 上传与结构解析

展示：

1. 材料名称、原始文件名、文件类型、文件哈希、上传时间。
2. 化学式、元素组成、原子数、结构类型、晶胞信息。
3. 结构校验错误、警告和建议。
4. 数据来源标签：`用户上传结构`。

结构无效时，仅提供“重新上传”或“查看错误”，不得显示后续化学建模入口。

### 4.2 活性位点确认

展示系统建议的位点列表。每条建议至少显示：

```text
位点标签
中心原子
相邻原子与配位数
识别方式
置信度
为什么建议该位点
```

提供两种操作：

1. 选择系统建议位点。
2. 手工指定中心原子与相邻原子。

用户确认后，页面必须显示：

```text
已确认活性位点：Fe-N4
确认人：当前用户
确认时间：...
说明：后续吸附模型和量子计算均基于该位点。
```

### 4.3 吸附构型选择

用户选择 `Li2S4`、`Li2S6` 或二者。页面展示系统生成的多个初始吸附构型：

1. 吸附物种。
2. 放置策略：Li 端朝向、S 链朝向、侧向吸附等。
3. 初始距离。
4. 几何质量提示与碰撞警告。
5. 三维结构预览或至少原子/键示意图。

必须显示说明：

```text
当前构型是初始几何，不等同于 DFT 优化后的稳定吸附构型，不能据此解读吸附能。
```

### 4.4 优化几何与外部 DFT 导入

提供两个明确分支：

| 模式 | 前端文案 | 可进入的后续能力 |
| --- | --- | --- |
| 初始几何预处理 | 仅消除明显原子碰撞 | 可构建测试量子区，不可作为科研筛选结论 |
| 导入外部 DFT 优化结果 | 使用外部软件优化后的结构 | 可进入高可信量子化学验证 |

导入外部 DFT 优化结果时，前端必须要求填写或上传：

1. 优化后结构文件。
2. 计算软件：VASP、Quantum ESPRESSO、CP2K、ORCA 或其他。
3. 交换关联泛函。
4. 基组或赝势。
5. 是否使用色散修正。
6. 自旋极化设置或初始磁矩说明。
7. 总电荷、总自旋/多重度。
8. 几何优化收敛说明。
9. 可选：计算日志、输出文件、文献 DOI。

缺少上述关键字段时，前端不得标记为 `dft_optimized`，只能标记为“导入结构，计算信息不完整”。

### 4.5 电荷、自旋与活性空间确认

这是本次新增的重点页面，适用于 `needs_model_review`。

页面必须使用非专业语言解释：

```text
电荷：局部量子模型带有多少净电荷。
自旋态：未成对电子的状态，会影响 Fe 等过渡金属催化位点的能量和反应能力。
活性空间：量子计算重点处理的少量关键电子轨道，不是整个材料的所有电子。
```

页面功能：

1. 显示系统生成的电荷/自旋候选，而不是默认只显示一个值。
2. 每个候选显示来源：用户导入、规则建议、DFT 已收敛候选或人工输入。
3. 显示 SCF 收敛状态、总能量、`<S^2>`、自旋污染提示和错误说明。
4. 对“自旋污染超阈值”“SCF 不收敛”等状态，显示下一步建议：
   - 选择另一个已收敛候选。
   - 导入 DFT 优化结构和计算信息。
   - 交给化学负责人复核。
5. 禁止把“随便填一个自旋多重度”设计成唯一的可继续路径。
6. 活性空间候选显示：`CAS(ne, no)`、电子数、轨道数、主要原子/轨道贡献、预计量子比特数、选择理由和资源风险。
7. 用户确认活性空间前，VQE 按钮必须禁用。

### 4.6 Hamiltonian、VQE 与分布式执行页

仅在后端实际完成对应任务后展示。

必须展示：

1. Hamiltonian 来源：结构 ID、量子区 ID、活性空间 ID、电子结构方法和基组。
2. 映射方法：Parity 或 Jordan-Wigner，是否使用 Z2 对称性裁剪。
3. 映射前后量子比特数、Pauli 项数、截断阈值与误差估计。
4. ansatz 类型、层数、参数数量、优化器、shots、收敛阈值。
5. VQE 迭代能量曲线：迭代次数、能量、误差条、是否收敛。
6. 分布式执行信息：执行后端、子线路数量、分配 QPU/模拟器、总 shots、测量重组状态。

结果标签必须从后端字段渲染：

```text
simulator：量子模拟器结果
qpu：真实量子硬件结果
geometry_only：仅几何预处理
imported_dft_result：用户导入的 DFT 结果
dft_optimized：平台或已验证来源的 DFT 优化结果
```

严禁在 `simulator` 状态下使用“量子芯片实测”“真实 QPU 结果”等文案。

### 4.7 结果与证据链页

结果页按证据强度分层展示：

| 层级 | 含义 | 可否用于最终推荐 |
| --- | --- | --- |
| 结构已解析 | 结构文件可用 | 否 |
| 初始构型已生成 | 已生成 Li2Sx 初始几何 | 否 |
| 模拟器量子化学验证 | 已完成局部 Hamiltonian/VQE | 仅作原型验证 |
| DFT + VQE 对照 | 有优化几何和基准对照 | 可作为科研候选依据 |
| 真实 QPU 验证 | 真实硬件测量且可追溯 | 可作为硬件验证证据 |

结果页需显示：

1. 当前结论可用范围。
2. 结果来源和模型限制。
3. 下一步建议。
4. 可下载/查看的 Artifact 列表：结构、构型、计算参数、Hamiltonian 摘要、QASM、VQE 迭代记录、日志摘要。

## 5. Fe-N4 + Li2S4 基准案例引导

前端应内置一个“基准案例”模板，用于演示和验收，但不能伪装为通用答案。

模板说明：

```text
案例：Fe-N4 位点与 Li2S4 吸附
用途：验证结构驱动化学建模和 VQE 工作流
注意：Fe-N4 的自旋状态会随局部配位与吸附环境改变，系统将比较可收敛候选，最终选择需要保留计算依据。
```

该提示来自相关 Li-S 研究：Fe-N4 的自旋可被轴向配位环境调节；Li-S 催化研究通常采用自旋极化 DFT 并分析吸附中间体的自旋/电子结构，而非预先写死一个自旋态。

## 6. 验收标准

1. 用户能从上传结构完整走到“需要科研确认”页面，且知道下一步需要什么信息。
2. `needs_model_review` 不再表现为技术报错或空白页。
3. 用户能导入优化结构及元数据，且前端会校验必填科研字段。
4. 用户能查看并确认活性位点、电荷/自旋候选与活性空间。
5. VQE 结果页只在后端真实返回 Hamiltonian 和执行记录后开放。
6. 页面能明确区分内置演示材料、用户上传结构、模拟器结果、DFT 结果和真实 QPU 结果。
7. 在 Fe-N4 + Li2S4 自旋污染超阈值时，页面显示可执行的复核建议，不能显示“筛选完成”。

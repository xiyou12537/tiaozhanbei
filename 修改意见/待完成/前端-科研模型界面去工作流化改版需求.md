# 前端：科研模型界面去工作流化改版需求

## 1. 背景与目标

当前系统已经能够将公开研究数据中的 `FeN4C66 + Li2S4` 模型作为可追溯输入接入平台。但界面直接显示“文献复现工作流”“文献优化几何已就绪”“阶段状态”等研发实现语言，容易让产品看起来像内部调试工具，而非面向研究人员的成熟材料建模系统。

本次改版采用“默认界面产品化、证据链按需查看”的原则：

```text
默认用户界面：模型选择、模型详情、计算准备情况、下一步操作
可展开详情区域：数据来源、方法参数、构型追溯、Artifact 与原始状态
```

本次仅调整信息架构、文案和前端展示；不得改变后端数据模型、候选选择逻辑、DFT/VQE 状态机或科学验证边界。

## 2. 设计原则

1. 用户操作对象是“科研模型”，不是“工作流”。
2. 公开数据集是模型来源，不是页面的主任务名称。
3. 后端状态码和内部阶段名称不得直接出现在默认界面。
4. 科学可追溯性必须保留，但收纳到“模型来源与方法”“计算记录”等可展开区域。
5. 不能因界面简化而弱化科学边界：未进行平台独立 DFT 重算时，仍须明确说明“独立计算验证尚未完成”。

## 3. 信息架构调整

### 3.1 导航与页面标题

| 现有表达 | 改为 | 说明 |
| --- | --- | --- |
| 文献基准 | 科研模型 | 导航入口名称 |
| 文献候选构型 | 模型构型 | 候选列表标题 |
| 文献复现工作流 | 模型详情 | 候选选定后的详情页标题 |
| 文献复现输入 | 已加载研究模型 | 创建成功提示 |
| 工作流 ID | 模型记录 ID | 仅在详情区域显示 |

路由可继续沿用现有地址，避免破坏既有链接；本次不要求修改 API 或数据库字段名称。

### 3.2 全局顶栏

在下列路由中移除全局“任务状态”“Workflow ID / Task ID”和所有“文献复现”状态文案：

```text
/app/research-benchmarks
/app/research-benchmarks/:benchmarkId
/app/structure-workflows/:workflowId
```

顶栏只显示当前页面标题，例如“科研模型”“模型构型”或“模型详情”。其他现有任务页可保留原有全局状态，不在本次改版范围内。

## 4. 页面需求

### 4.1 科研模型概览页

页面主标题使用：

```text
Fe-N4/C 催化模型
```

副标题使用：

```text
用于 Li2S4 吸附与后续量子化学分析的研究模型
```

默认首屏展示：

1. 催化位点：`Fe-N4`。
2. 吸附物：`Li2S4`。
3. 模型类型：周期性碳载单原子催化模型。
4. 可用构型数量。
5. 主操作：“选择模型构型”。
6. 简洁的计算边界提示：“当前模型已加载；独立计算验证尚未完成。”

不得将“Materials Cloud”“论文 DOI”“CC-BY-4.0”“reproduction_baseline_only”作为首屏主视觉或标签。它们放入折叠的“模型来源与方法”区域。

### 4.2 模型构型页

页面标题为“选择模型构型”，说明文案为：

```text
请选择一个构型作为后续计算分析的起点。构型的来源信息和原始记录可在详情中查看。
```

列表列名调整如下：

| 现有表达 | 改为 | 默认展示 |
| --- | --- | --- |
| 文献候选 ID | 构型编号 | 是 |
| 优先序 | 构型序号 | 是 |
| 源能量 | 参考能量 | 是，必须保留“原始单位，未确认”说明 |
| 组成校验 | 组成检查 | 是 |
| 文献候选构型 | 可用状态 | 是，显示“可用于建模”或“需要检查” |
| 查看 | 查看详情 | 是 |

选择确认弹窗改为：

```text
将以该构型创建一个独立的模型记录，供后续计算分析使用。

模型来源、构型编号和原始记录会被保留，以保证结果可追溯。
当前操作不会执行独立 DFT 计算，也不会生成可用于材料推荐的吸附能。
```

成功提示改为“研究模型已加载”，随后进入“模型详情”。

### 4.3 模型详情页

移除纵向“工作流阶段”时间线作为默认主体，改为以下四个信息区：

| 区域 | 默认内容 | 用户语言 |
| --- | --- | --- |
| 当前模型 | `Fe-N4/C + Li2S4`、构型编号、模型记录 ID | 当前研究对象 |
| 建模准备情况 | 结构、活性位点、吸附构型、几何是否已准备 | 已加载 / 已确认 / 可继续分析 / 尚未开始 |
| 下一步 | 量子区设置、活性空间、Hamiltonian、VQE 的可用性 | 下一步操作建议 |
| 模型来源与方法 | 公开数据集、DOI、计算参数、Artifact、警告与原始状态 | 默认折叠，按需查看 |

“建模准备情况”使用以下映射：

| 后端状态 | 默认界面文案 |
| --- | --- |
| `literature_reproduction_input_selected` | 研究模型已加载 |
| `literature_reproduction_geometry_ready` | 几何已准备，可继续分析 |
| `literature_selected` | 已选定模型构型 |
| `completed`（文献几何） | 已载入参考几何 |
| `not_started` | 尚未开始 |

不得在默认界面显示：

```text
文献复现工作流
文献优化几何已就绪
reproduction_baseline_only
literature_open_dataset
literature_reproduction_geometry_ready
Workflow
Task
```

“模型来源与方法”展开后必须保留以下科学事实：

1. 数据来自公开研究数据集，显示 Materials Cloud 与 DOI 链接。
2. 当前为参考模型输入，平台独立 DFT 重算尚未完成。
3. 参考能量为数据集原始值，单位语义未确认，不是吸附能。
4. 显示实际返回的计算方法参数和 Artifact 元数据。

### 4.4 未开始计算阶段

量子区、活性空间、Hamiltonian 和 VQE 未创建时，不显示技术错误、空白成功卡片或模拟结果。统一展示：

```text
尚未开始计算分析
完成前置建模确认后，可在此继续设置和执行计算。
```

只有后端返回真实对象和结果后，才显示相应详细内容；`simulator` 与 `qpu` 仍须严格按后端来源标识。

## 5. 保留的科学与追溯要求

1. 不能删除来源 DOI、数据集链接、许可证、数据集版本、哈希和 Artifact 下载能力。
2. 不能把参考能量改名为吸附能、结合能或稳定性结论。
3. 不能把载入的参考几何表述为“平台 DFT 已完成”。
4. 不能自动选择最终自旋态，不能隐藏 `needs_model_review` 等质量门槛；但默认展示应转换为可理解的行动提示。
5. 所有原始后端状态可保留在“模型来源与方法”中，供科研复核。

## 6. 验收标准

1. 上述三个页面的默认首屏和全局顶栏中不出现“工作流”“文献复现”“Workflow”“Task”或原始状态码。
2. 用户能从“科研模型”进入构型选择、选择构型并到达“模型详情”，不需要理解后端状态机。
3. 模型详情默认可判断当前模型、准备程度和下一步；来源与证据链可展开查看。
4. 科学边界仍然清晰：独立 DFT 未完成、参考能量单位未确认、参考能量不是吸附能。
5. 现有基准发现、候选选择、Artifact 查看/下载、文献模型状态同步和路由跳转不回归。
6. 更新 Chromium 页面测试，断言默认界面不出现禁用术语，同时断言展开详情后可查看来源与科学限制。
7. 前端构建、文献基准单元测试、Chromium 页面测试均通过。

## 7. 非范围

1. 不修改或重跑 DFT、VQE、量子区或活性空间计算。
2. 不改变后端 API 字段、数据库表、权限与 Artifact 授权逻辑。
3. 不修改普通多材料筛选和用户上传结构建模页面的状态设计。
4. 不将产品化文案用于伪造科学结论。
